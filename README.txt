FlowGet 0.3.0 源码 — IDM 行为规格驱动的独立实现
2026-10-19

本轮更新
  FTP 文件下载：匿名或账号登录、被动单连接、限速、重试、SHA-256 校验。
  FTP 条件续传：需要 SIZE、MDTM 和 REST；元数据变化或 REST 被拒绝时重下。
  多队列：独立并发上限、启停、一次性定时启动/停止、任务移动与队列内排序。
  全局并发上限始终有效；队列间轮流获取空闲槽位，避免单队列长期占用。
  站点抓取：HTML 链接和资源发现、同站点/目录范围、深度与类型筛选、预览导入。
  抓取结果可多选加入指定队列，自动去重并以暂停状态保存。
  原 0.1 / 0.2 任务自动归入默认队列，任务状态及全局设置保持兼容。

0.2 保留功能
  队列顺序可上移/下移，支持多选；重启后保留调度顺序。
  列标题支持排序；「顺序」列恢复实际队列顺序，列表排序不改变调度顺序。
  暂停或失败任务可编辑文件名、连接数、单任务限速及下载地址。
  更新地址会重新下载，旧分段在下一次下载准备时清理，不拼接不同地址的内容。
  仅修改名称/限速时仍尝试校验续传；连接数更改在重建分段时生效。
  单任务限速在各分段间共享，并同时受全局限速约束。
  定时启动与定时停止均为一次性计划，使用运行电脑的本地时间。
  界面增加分类计数、独立等待队列、交替行底色、选择状态与按钮禁用状态。
  增加总速度曲线、实时分段详情、横向滚动与 Delete / Enter / Ctrl+A 交互。

使用
  新版：python app.py；Windows 打包后双击 FlowGet.exe，无需安装 Python。
  新建下载 / Ctrl+N：粘贴 HTTP / HTTPS / FTP 直链，选择目录及目标队列。
  「连接 / FTP / 校验」页签可设置连接数、限速、哈希与 FTP 登录信息。
  Ctrl+V：在主界面粘贴剪贴板中的下载链接，不会自动读取剪贴板。
  选择任务后可暂停、继续，双击查看属性。右键可复制链接或移除记录。
  设置中可调整连接数、同时下载数、总限速、默认目录和一次性定时启动。
  「队列」按钮停止队列时会暂停活跃任务；再次开启只调度等待队列任务。
  手动暂停的任务需要选择后点击「继续」。
  全部任务按队列顺序排列；上移/下移将改变等待任务的调度次序，不抢占活跃任务。
  更新下载地址：先暂停并等待停止，然后点击「编辑 / 更新地址」。保存后需手动继续。
  全局限速优先约束总流量，单任务限速的 0 仅表示该任务没有额外上限。
  定时启动要求程序持续运行，不会创建 Windows 后台计划任务。
  退出时保存并暂停活跃任务，下次启动后需手动继续这些任务。

FTP 使用
  使用 ftp://主机[:端口]/目录/文件；用户名和密码通过界面单独输入。
  默认 anonymous；密码只保留在内存，不写任务、分段记录或导出链接。
  非匿名任务重启后，右键「FTP 登录」重新输入密码，再点击继续。
  FTP 为明文协议，当前不支持 FTPS/SFTP，也不使用 HTTP 代理。
  FTP 使用一个数据连接；设置中的多连接数只适用于 HTTP/HTTPS。
  SIZE+MDTM 仅是服务器元数据，不等同于 HTTP 强 ETag；需要端到端内容
  校验时请填写可信来源的预期 SHA-256。同大小且同修改时间的变化无法检测。

多队列使用
  顶部「管理队列」可创建、重命名、设置并发、启停及删除空队列。
  在主界面选择已停止的任务，右键「移动到队列」，选定目标后点击移入。
  顶部队列选择器切换视图；新建/导入默认使用当前队列，全部视图用默认队列。
  「全部停止/启动」控制全局开关；工具栏「停止/启动队列」控制当前队列。
  队列定时启停不改变全局开关，全局停止时独立队列计划不会开始传输。
  降低并发上限不打断已有连接，等待活跃任务自然降到上限后才发起新任务。
  默认队列不可删除；删除其他队列前必须先移走全部任务，不删除下载文件。

站点抓取使用
  点击「站点抓取」，输入起始网页、深度、最多页面及扩展名，开始抓取。
  深度 0 只解析起始页面；该页面中的文件资源仍可被发现。
  默认限制在起始页所在目录及子目录，取消目录限制后仍限同站点。
  遵守 robots.txt，跳转也检查范围和 robots；403/401 禁止抓取，404 表示无规则。
  robots.txt 其他错误停止抓取并显示原因。支持从 HTTP 升级至同站点 HTTPS。
  最多 500 页、1000 个资源、单页 2 MB、总网页 20 MB；默认页面请求间隔 150 ms，
  robots.txt 声明 Crawl-delay 时取更长的间隔。停止可能需等待当前连接超时。
  结果列表 Ctrl+A 全选或 Ctrl/Shift 多选，选择目标队列后点击「加入选中资源」。
  不执行 JavaScript、不导入登录 Cookie、不进行离线镜像链接改写；登录型网站、
  由脚本生成的链接及 HLS/DASH 不在本版抓取范围内。

已实现
  HTTP/HTTPS；1–32 个连接；最多同时下载 8 个任务。
  强 ETag 与 Content-Range 校验；中断重试；跨程序重启续传。
  服务端不支持范围请求、未提供强 ETag 时采用单连接完整传输。
  总限速、一次性定时队列、任务持久化、分类筛选、名称/链接搜索。
  速度、进度、剩余时间、每个分段的进度和错误信息。
  TXT 批量链接导入/导出；导入后暂停以便检查；Content-Disposition 文件名。
  完成后 SHA-256；可选预期 SHA-256，不匹配时不发布成品。
  同名文件保留，使用 (1)、(2) 等新名称；下载完成不会自动运行文件。
  已提供浏览器主动发送链接扩展与本地桥接，尚未安装或实际浏览器联调。
  FTP、多队列及站点抓取能力见上述专项说明。

数据位置
  任务与设置：%LOCALAPPDATA%\FlowGet\tasks.json
  默认成品：用户的 Downloads\FlowGet，可为每个任务另选目录。
  分段：每个保存目录下的 .flowget-parts\任务ID。
  移除记录会保留成品与分段，不会擅自清理用户数据。
  测试可用 FLOWGET_DATA_DIR 环境变量指定隔离的任务目录。

当前边界
  这是分阶段的早期可运行版本，不是完整 IDM 替代品。
  浏览器自动接管、Cookie/Referer、登录型链接、流媒体发现/HLS/DASH、
  导入 IDM 历史尚未实现；已支持手动替换过期地址，
  尚不支持自动查找新地址或跨新地址保留续传进度。
  不读取 IDM 密码、下载历史或注册信息，不修改 IDM 文件。
  分段策略是独立固定范围划分，尚未实现动态工作窃取或证明等速。
  目标磁盘需支持硬链接，如 NTFS；FAT/exFAT 不在本版范围内。
  合并过程最多需要约两倍文件大小的可用磁盘空间。
  Windows 默认采用系统 curl（Schannel），域名优先 IPv4。
  Python 后端作为备用，IPv6 专用网络尚未验证。
  任务文件保存完整 URL；含临时签名的 URL 应按个人数据保管。
  HTTP 没有强 ETag 时会重新完整下载；FTP 恢复按上述元数据条件判断。
  本版没有导入浏览器登录状态，也不会绕过服务器的权限要求。

项目文件
  app.py           桌面界面。
  engine.py        下载、校验、状态与队列。
  transport.py     系统 curl 的流式适配层。
  ftp_transport.py 被动 FTP 连接与元数据探测。
  grabber.py       有范围与预算限制的站点资源发现。
  feature_dialogs.py / ui_base.py  多队列、FTP 登录、抓取窗口及共享界面组件。
  native_host.py   Native Messaging 桥接。
  browser-extension/  Edge / Chrome 主动发送链接扩展。
  register-browser.ps1 / unregister-browser.ps1  可审阅的注册与卸载脚本。
  SPECIFICATION.txt 观察证据、独立规格和后续阶段。
  tests/           可重跑的 HTTP、FTP、多队列、抓取与桌面交互测试。
  verification/    测试结果与真实 HTTPS 文件的哈希核对结果。
  build.ps1        从源码重新打包。

源码运行
  Python 3.12+ + Tk 8.6；仅使用标准库，不需 pip 运行时依赖。
  python app.py

测试
  python -m unittest discover -s tests -p "test_*.py" -v
  node --test tests/extension.test.js
  界面测试需要桌面显示；无显示的 Linux 环境自动跳过，不计为界面验证通过。
  默认在 Windows 测系统 curl 后端。
  设置 FLOWGET_TEST_BACKEND=urllib 可测试 Python 后端。

与 IDM 的关系
  本程序名为 FlowGet，与 Tonec / Internet Download Manager 无隶属关系。
  没有复制 IDM 的代码、图标、图片、注册机制或私有存储格式。
  本轮是依据可观察界面和公共 HTTP 标准的独立重写；未安排互相隔离的
  两支团队，因此不声称满足有独立人员隔离审计的严格净室证明。
